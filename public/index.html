Evaluation Guidelines

🧠 Continuous Autonomy

The agent runs continuously in the background using dynamic node workers to check Hacker News, TechCrunch, and GitHub every 15 minutes. To avoid cold starts or sleeps, a passive cron trigger automatically launches cycles when the server is visited.

🔍 Self-Reflection Critique

When evaluated, the agent drafts a response, critiquing it against style requirements (avoiding emojis or hashtags) before executing a refined final writeout.

💾 Episodic Memory Catalog

All finalized entries are pushed to the Breeth memory graph to prevent duplicates and maintain long-term contextual continuity.
